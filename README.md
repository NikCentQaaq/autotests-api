# Автоматизированные API-тесты

Этот проект содержит автоматизированные тесты для  
[API Course Test Server](https://github.com/Nikita-Filonov/qa-automation-engineer-api-course).

Тесты написаны с использованием **Python**, **Pytest**, **Allure**, **Pydantic**, **Faker** и **HTTPX**.

Исходный код тестового приложения доступен на [GitHub](https://github.com/Nikita-Filonov/qa-automation-engineer-api-course).

## Обзор проекта

Цель проекта — автоматизация тестирования API-сервера курса с использованием подходов REST API testing.

Автоматизированные тесты проверяют различные функциональные возможности приложения, обеспечивая стабильность работы и корректность API.

Проект разработан для API-автотестирования и включает следующие практики:

- **API Clients** — отдельный слой для структурированного взаимодействия с API-эндпоинтами;
- **Pytest fixtures** — создание переиспользуемых фикстур для удобной настройки тестового окружения;
- **Pydantic models** — строгая валидация данных запросов и ответов;
- **Schema validation** — проверка соответствия ответов API заданной структуре;
- **Генерация тестовых данных** с помощью **Faker** для имитации реальных пользовательских сценариев;
- Использование дополнительных подходов для повышения надежности, читаемости и эффективности тестов;
- Структура проекта соответствует индустриальным стандартам, обеспечивая удобство поддержки и дальнейшего масштабирования тестового кода.
